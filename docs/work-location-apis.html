Work Location APIs

Sixteen REST endpoints in the policies-web-services workLocation module. Flows are traced from the controller through AuthZ, data-accuracy, the Sync SDK vs DAL-write fork, IOP, and PWS (wlc schema).

Shared write fork: location and V2 assignment writes go through WorkLocationIopV2DalWriteHelper — feature flag SWITCH_TO_V2_FOR_WORK_LOCATION_DAL_WRITE (or the employee-assignment sibling), skip-version-bump header, and IOP sync-in-progress guard (HTTP 307). Legacy path: Sync SDK (IOP REST, then PWS commit). DAL-write path: validate → IOP V2 Hibernate → PWS; PWS failure after IOP success resets the data duality tracker. V3 additional assignments use commit-PWS-then-notify-IOP.
